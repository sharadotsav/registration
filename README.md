# 🌺 Sharadotsav - Official Registration Portal

An official and modern web-based registration portal designed for **Sharadotsav**, organized by **Manokamnapurn Durga Puja Samiti, Mirzapur** (Ward No-02, Chhoti Durga Sthan, Rosera, Samastipur, Bihar - 848210).

## 🌟 About The Project
This portal allows participants to seamlessly register for cultural events such as **Dance** and **Singing Competitions** (Solo & Group). It features a dynamic, mobile-friendly interface with instant SheetDB integration to store registration records directly into Google Sheets.

## ✨ Key Features
- **Dual Event Support:** Easily switch between Dance and Singing registration forms with tailored style/genre dropdowns.
- **Solo & Group Options:** Dynamic co-performer/co-singer fields that enable/disable automatically based on the participation type.
- **Google Sheets Integration:** Real-time data storage using SheetDB API.
- **Unique Registration ID Generator:** Generates custom prefixes (`DN` for Dance, `SG` for Singing) tracked via local storage.
- **Modern UI/UX:** Built with *Plus Jakarta Sans* font, smooth glassmorphism shadows, and fully responsive layouts for mobile and desktop devices.
- **Instant Success Modal:** Provides participants with a unique registration number and screenshot reminder for venue reporting.
